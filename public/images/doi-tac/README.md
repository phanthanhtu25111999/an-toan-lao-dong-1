# Logo đối tác

Đặt file logo (nền trong suốt, `.png`/`.svg` là tốt nhất) của từng đối tác vào
đây, sau đó điền đường dẫn vào field `logo` tương ứng trong
`src/content/partners.ts`, ví dụ:

```ts
{ name: "Vinpearl", logo: "/images/doi-tac/vinpearl.png" }
```

Cho tới khi có logo thật, các đối tác sẽ hiển thị dạng chữ (wordmark) thay
logo — tôi không tự tải logo thương hiệu của các đối tác từ nguồn khác vì có
thể không đúng bản quyền/phiên bản logo mới nhất, nên cần bạn cung cấp file
chính chủ.
